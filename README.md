# Final Year Computing Modules Repository

This repository contains academic materials from my **Final Year (Level 6)** of the Computing degree program at the **Informatics Institute of Technology (IIT), Sri Lanka**, which is affiliated with the **University of Westminster**.

It focuses on advanced, industry-aligned modules: applied artificial intelligence, usability testing and UX research, and information-driven entrepreneurship. It includes lecture materials, tutorials, coursework implementations and supporting resources.

## 🛠 Running the Code

- **Jupyter notebooks:** install Python 3 with `pip install pandas numpy scikit-learn matplotlib seaborn jupyter`, then run `jupyter notebook` and open the `.ipynb` file.
- **SPSS files:** `.sav` data files and `.spv` output files open in IBM SPSS Statistics. The free alternative PSPP can open the `.sav` files.
